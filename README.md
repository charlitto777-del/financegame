# Révision Structure Financière

Site de révision pour le cours « Structure financière de l'entreprise » (Centrale Lille) : SIG, CAF, bilan fonctionnel.

- Grilles de l'examen à remplir et à valider ligne par ligne, avec renvoi au cours en cas d'erreur.
- Sept sujets, dont l'examen 2025-2026 et deux sujets d'entraînement inventés.
- Tri des postes, quiz et fiche « Jour J ».

Tout est dans `index.html`. Les saisies sont enregistrées dans le navigateur (localStorage).
